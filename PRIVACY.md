## 中文

### 数据收集

**本扩展不收集任何数据。**

- 不收集个人身份信息（姓名、邮箱、账号等）
- 不收集浏览历史、网页内容、表单输入
- 无远程服务器、无遥测、无分析埋点、无广告
- 不向任何第三方传输数据

### 数据存储

- 用户设置（手势配置、命令绑定、排除项等）仅存储在您的浏览器本地（`chrome.storage.local`）
- 扩展不会将任何设置上传、同步或备份到云端
- 卸载扩展即删除全部本地数据

### 权限说明

| 权限 | 用途 |
|:---|:---|
| 读取所有网站数据 (`<all_urls>`) | 在所有网页中注入手势检测与绘制——这是鼠标手势功能的核心要求 |
| `scripting` | 执行页面内命令与用户自定义脚本 |
| 可选权限（按需请求） | 高级命令使用：tabs / sessions / bookmarks / clipboard / downloads / search / browsingData |

### 第三方

本扩展基于 [Gesturefy](https://github.com/Robbendebiene/Gesturefy)（GPL-3.0，作者 Robbendebiene）移植，与原版一致，不包含任何第三方服务、SDK 或跟踪器。

## English

### Data Collection

**This extension collects no data of any kind.**

- No personally identifiable information (name, email, account, etc.)
- No browsing history, page content, or form input
- No remote servers, no telemetry, no analytics, no advertising
- No data transmitted to any third party

### Data Storage

- User settings (gesture config, command bindings, exclusions, etc.) are stored only in your browser's local storage (`chrome.storage.local`)
- The extension never uploads, syncs, or backs up any settings to the cloud
- Uninstalling the extension deletes all local data

### Permissions

| Permission | Purpose |
|:---|:---|
| Access all website data (`<all_urls>`) | Inject gesture detection and drawing into every webpage — the core requirement of mouse gesture functionality |
| `scripting` | Execute in-page commands and user-defined scripts |
| Optional permissions (requested on demand) | Advanced commands: tabs / sessions / bookmarks / clipboard / downloads / search / browsingData |

### Third Parties

This extension is a port of [Gesturefy](https://github.com/Robbendebiene/Gesturefy) (GPL-3.0, by Robbendebiene). Like the original, it contains no third-party services, SDKs, or trackers.
